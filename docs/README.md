# docs

המסמכים של הריפו לבני אדם ולסקילים: מה הריפו עושה, למה הוחלט כך, ומה למדנו.

## מדריך קבצים

| קובץ | מה הוא |
|---|---|
| `specs/claude-config.md` | האפיון של הריפו: פרק לכל נושא, וחלק עם מזהה ושורת מצב לכל דבר שהריפו עושה. |
| `specs/README.md` | הפורמט של האפיון: המזהים, שורות המצב, ושורת `אפיון:` ב-issue. |
| `decisions/*.md` | דף לכל החלטה שחוצה משימות, עם הרקע, החלופות שנדחו והמחיר, לפי הנוהל ב-`rules/code-general.md`. |
| `retros/151-global-config.md` | רטרו חד-פעמי של ספרינט עם המתזמר: איפה חיכו, ואילו שיפורים הוצעו. |
