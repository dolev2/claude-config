# לקח נכנס לכללים רק ב-PR שדולב מיזג

**מצב:** בתוקף · **תאריך:** 2026-11-10 · **issue:** #182

## רקע
לקחים נכנסו לכללים רק כשמישהו זכר לכתוב אותם ביד, או נשמרו בזיכרון של פרויקט אחד בלי מקור.
לקחים מסשנים אחרים הלכו לאיבוד.
הרעיון בא מהסקיל `agentic-brain-group`: "המודל מציע, האדם מחליט".

## החלטה
1. **Claude מציע לקח אחד לכל היותר**, בסוף `dev-code` ובסוף `dev-ship`, כל אחד ממה שקרה אצלו, עם מקור.
2. **ההצעה היא שאלה בחלון השאלות.** בן של מתזמר כותב אותה בהערת המסירה, והמתזמר שואל.
3. **אישור פותח משימה בספרינט הנוכחי.** בלי אדם בצ'אט, הלקח נפתח כהצעה בבקלוג.
4. **לקח נכנס לכללים או לסקיל רק ב-PR שדולב מיזג**, עם המקור והתאריך בסוף השורה.
5. **לקח שמחליף ישן אומר את זה בשורה שלו, והישן נמחק.** ההיסטוריה ב-git וב-issue.

הכלל המלא: `skills/dev-setup/reference/lessons.md`.

## חלופות שנדחו
1. **כתיבה ישירה לכללים או לזיכרון:** בלי בדיקה ובלי מקור.
2. **כל לקח כמשימה בבקלוג:** הבקלוג מתמלא בלקחים שהיו נדחים בלחיצה.
3. **לקח רק בסוף אחד השלבים:** מוקשים של השלב השני לא נתפסים.
4. **יומן לקחים נפרד, או לקח ישן שנשאר מסומן:** עוד קובץ לתחזק, או כללים שמתארכים, והם נטענים בכל סשן.
5. **לקח בכל ריצה:** רעש, ודולב מפסיק לקרוא.

## מחיר
