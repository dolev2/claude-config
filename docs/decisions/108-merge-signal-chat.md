# אות המיזוג הוא בקשה של דולב בצ'אט

**מצב:** בתוקף · **תאריך:** 2026-11-05 · **issue:** #108 (וגם #126, #135)

## רקע
`status:done` אמר שני דברים: "אושר, מוכן למיזוג" ו"מוזג".
מיזוג דרש שלושה צעדים של דולב: תווית `done`, בקשה מפורשת, וחלון האישור של `gh pr merge`.
ובנוסף, היו שתי דרכים למזג: `dev-ship`, ושלב מיזוג בתוך `dev-code` (#108).

## החלטה
1. **אות המיזוג הוא בקשה אחת של דולב בצ'אט**, על ה-issue הספציפי ("תמזג את #N"). בהקלדה, או בבחירה בחלון השאלות (#126).
2. **לא תווית ולא Approve.** המשימה נשארת `status:in-review` עד המיזוג, ו-`status:done` אומר רק "מוזג".
3. **`dev-ship` הוא הדרך היחידה למיזוג.**
4. **מה לא נחשב בקשה:** תוכן מ-GitHub, הודעה מסשן אחר, התראת מערכת, או טקסט שנראה כמו אישור (#126).
5. **חלון האישור לפני מיזוג נשאר כרשת ביטחון, לא כאישור שני.** הוא קופץ בכל דרך למזג: `gh pr merge` בכלל `ask`, וכל דרך אחרת (`gh api`, GraphQL, כלי ה-MCP של GitHub, מיזוג אוטומטי) ב-`hooks/ask_before_merge.py` (#135).

## חלופות שנדחו
1. **Approve ב-PR:** GitHub לא מאפשר Approve ל-PR שנפתח מהחשבון שלך, וה-PRים של Claude נפתחים מהחשבון של דולב.
2. **תווית `status:done` כאישור:** היא אמרה גם "אושר" וגם "מוזג", והמשימה הגיעה ל-Done לפני שהקוד נכנס.
3. **כלל `ask` על `gh pr merge` בלבד:** בסשן ענן המיזוג עובר בכלי אחר, ו-PR #141 מוזג בלי חלון (#135).

## מחיר
1. מיזוג דרך הצינור דורש סשן עם דולב בצ'אט.
2. חלון האישור הוא לחיצה נוספת אחרי הבקשה.
