# הפירוק לא שער: פירוק ופיצול נפתחים בלי שאלת אישור

**מצב:** בתוקף · **תאריך:** 2026-11-18 · **issue:** #485 (מההצעה #468)

## רקע
כל פירוק ופיצול חיכו לאישור של רשימת ה-issues, אחרי שהאפיון כבר אושר במיזוג.
אחרי מיזוג של אפיון, `dev-ship` הציע את הפירוק בחלון, ו-`dev-issue` הראה שוב את הרשימה לפני שפתח משהו.
במתזמר, הפירוק עלה בחלון בכל בדיקה עד שדולב ענה.
הדף האח: `466-plan-is-not-a-gate.md`, שהוציא את אישור התוכנית.

## החלטה
1. **דולב מאשר שני דברים בלבד:** את האפיון, במיזוג שלו, ואת הקוד, בסקירה של המסירה.
2. **פירוק ופיצול נפתחים ישר** (S-1.66): פירוק של אפיון שמוזג, פירוק או פיצול שדולב ביקש, ופיצול שבן מציע במתזמר.
3. **כל issue מקבל milestone.** בלי מקור (דולב לא נקב, ואין להורה ואין להצעה): milestone פתוח שמתאים לנושא, או חדש בשם הנושא. הדוח אומר לאיזה.
4. **מה שנשאר שאלה:** תלות שנראית חסרה באפיון, issues ש-Claude מציע מעצמו, והעדכון של issues קיימים אחרי שינוי באפיון (S-1.34), כי הוא סוגר issues.

## חלופות שנדחו
1. **להשאיר את שאלת הרשימה, עם "לפתוח (מומלץ)" ראשון:** זו עדיין עצירה, ועדיין אישור שני של אותו "מה".
2. **לפתוח בלי milestone, ולתת לדולב לשייך:** issue בלי milestone לא נראה בשום סריקה, ונעלם מהעין.
