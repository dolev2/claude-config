# שינוי בסקיל נבדק בתרחישים קבועים מול GitHub מדומה

**מצב:** בתוקף · **תאריך:** 2026-11-10 · **issue:** #183

## רקע
הסקילים משתנים הרבה (31 שינויים בחודש), והבדיקות בריפו מכסות רק את הסקריפטים וה-hooks.
שינוי בטקסט של `SKILL.md` שמקלקל כלל (מיזוג בלי בקשה, עצירה בסקירה, סעיפים שאדם כתב) לא נתפס עד שהוא קורה באמת.

## החלטה
1. **`claude plugin eval` דרך עטיפה, `evals/run.py`.** היא בונה plugin זמני מ-`skills/`, ומריצה את התרחישים מול GitHub מדומה (`evals/fake_gh.py`) וריפו דוגמה עם remote מקומי.
2. **תרחישים לפי סקיל** ב-`evals/cases/`, עם תגית בשם הסקיל. רק מה שיקר לשבור, ורוב הבודקים לא עולים כסף.
3. **סט שמור בצד** ב-`evals/holdout/`, שלא מכווננים עליו. PR שמשנה סקיל לא משנה אותו, ו-`.github/holdout_check.py` נכשל על שניהם יחד.
4. **הרצה מותנית בסשן הקוד**, כשה-diff נוגע בסקיל מכוסה, במסמכי הצינור או ב-`evals/`. לא ב-CI.
5. **על המנוי, במודל של הסשן** (`--model` עם המזהה שלו), שתי הרצות לתרחיש. אין הוצאה כספית, רק צריכה מהמכסה.
6. **בענן וב-Linux בלבד:** Bash בתרחיש דורש sandbox (`bubblewrap`, `socat`). ב-Windows אין לו backend.
7. **שלב ראשון: `dev-ship`, `dev-code`, `dev-plan`.** שאר הסקילים מקבלים תרחישים במשימות המשך.

## חלופות שנדחו
1. **בדיקת pytest על הטקסט של `SKILL.md`:** בודקת ניסוח, לא התנהגות.
2. **הרצה מול GitHub אמיתי בריפו בדיקה:** לא חוזרת על עצמה, ומסוכנת למיזוג.
3. **הרצה ב-CI עם מפתח API:** כסף אמיתי, הערכה של עשרות עד מאות דולרים בחודש.
4. **הרצה רק בבקשה מפורשת:** שינוי ששובר כלל נכנס בלי שאף אחד הריץ.
5. **מודל זול יותר:** מתנהג אחרת, והציון פחות אומר.

## מחיר
1. צריכה ממכסת המנוי בכל PR שנוגע בסקיל. נמדד: כ-0.43 דולר נומינלי להרצה של תרחיש `dev-ship`.
2. תרחישים שצריך לתחזק כשכלל משתנה בכוונה.
3. לא רץ ב-Windows, ולא בלי סשן.
4. ה-GitHub המדומה עונה רק על הפקודות שהסקילים מריצים היום. פקודה חדשה נרשמת כלא נתמכת, ויש להוסיף אותה ל-`evals/fake_gh*.py`.
5. התרחישים בודקים התנהגות, לא ניסוח. כלל שכתוב בכמה מקומות (העצירה לפני מיזוג: `dev-code`, `dev-ship`, `git.md`, `pipeline.md`) לא נשבר כשמוחקים אותו ממקום אחד, והתרחיש עובר. בהוכחה זה קרה גם כשהכלל נמחק משלושה מקומות: המודל זיהה את הסתירה ולא מיזג. כלל שכתוב במקום אחד (`dev-ship` שלב 6, `status:done`) נתפס בהרצה הראשונה.
6. תרחיש שהבקשה בו לא מפעילה את הסקיל ("מה המצב של #12?") בודק את התיאור של הסקיל ואת ההנחיות הכלליות, לא את גוף הסקיל.
