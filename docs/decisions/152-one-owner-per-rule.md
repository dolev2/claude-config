# לכל כלל בצינור קובץ בעלים אחד

**מצב:** בתוקף · **תאריך:** 2026-11-10 · **issue:** #152

## רקע
כל כלל בצינור היה כתוב ב-4 עד 5 מקומות: מסמכי הצינור, הסקילים, הכללים ב-`rules/` ו-`.claude/CLAUDE.md`.

העותקים התחילו לסתור זה את זה: שער ה-WIP, הדיווח של סשן-בן, פקודת Edge ופקודות הבדיקה.

סוכן שקרא עותק אחד עבד לפי נוסח ישן, ובלי שום סימן לכך.

## החלטה
1. **לכל כלל קובץ בעלים אחד**, לפי המפה ב-`skills/dev-setup/reference/owners.md`. שם הנוסח המלא: הכלל, הנימוק והחריגים.
2. **מקום אחר מפנה בשם הקובץ, ולא מעתיק.** ההפניה בשם קובץ ולא בשם כותרת, כמו שהבדיקות של #99 אוכפות.
3. **הסקיל מחזיק רק את הצעד שהוא מבצע**, ואת הפקודה שהוא מריץ.
4. **נקודת הכניסה לבני אדם היא העמוד "חייו של issue", ולסוכנים המפה.**
5. **שינוי בכלל מעדכן את הבעלים**, ואת התרשים ושני העמודים באותו PR, כמו קודם.
6. **עותק מכוון** (פקודות הבדיקה ב-`README.md`) מסומן במפה, ונשמר בבדיקה שנכתבת ב-#248.

## חלופות שנדחו
1. **מסמך אחד גדול:** עובר את תקרת 150 השורות של מסמכי הצינור, וכל סקיל היה טוען את כולו.
2. **להשאיר את העותקים ולסנכרן ביד:** זה בדיוק מה שסטה.
3. **רק הכלל הקיים, בלי בדיקות:** נדחה בשאלה 4 ב-#152. בלי בדיקה, עותק מכוון סוטה כמו כל עותק.

## מחיר
סוכן שקורא סקיל פותח עוד קובץ כדי לראות את הכלל המלא.

הפניה לקובץ שהשתנה בלי לעדכן את המפה עלולה להוביל לקובץ הלא נכון, עד שהבדיקה של #248 תופסת את זה.
